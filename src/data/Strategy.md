# Strategy
Given the several pipelines required to scale and procure the data for the RLFR pipeline we use a sophsicated tracking system to parallelize this and allow users to use this as an out of the box tool and allow for rapid experimentation and testing.

# Prefect

We use prefect because we use several nodes to procure and produce the data and given the asynchronus processes it is optimal to interact with our application through a programatic restful and asynchronus interface.
